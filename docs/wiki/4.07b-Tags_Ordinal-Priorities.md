# Tags: Ordinal-Priorities

Super Productivity has built-in High, Medium, and Low task priorities. Choose a priority from the task context menu, or set it for several selected tasks at once; the task row shows a compact indicator, and the task-view customizer can sort and filter by priority. Clearing the priority returns the task to None.

Tags remain useful when you need more levels or a custom vocabulary. For certain tag types you could use a prefix to make it easier to filter them. For example, your tags might look like:

- `#P1 #P2 #P3 #P4` (P for priority)
- `#I-LOW #I-MED #I-HIGH` (I for importance)
