# Import from Microsoft To Do

Bring your open Microsoft To Do lists, tasks, steps, notes, due dates and repeats into Super Productivity in one pass. The import is **additive**: it only creates new projects, tags and tasks and never changes or removes existing Super Productivity data.

Available in the desktop app and the official web app. It is not available in the Android and iOS apps, and sign-in does not work on a self-hosted web copy (Microsoft only accepts sign-ins returning to registered addresses).

## What you need

- A **Microsoft account** (personal, work or school) that uses Microsoft To Do. You sign in with Microsoft in a browser window; the import asks only for permission to read your tasks. The sign-in is used for this import and then forgotten. Some work or school accounts only allow apps their administrator has approved — if Microsoft asks for admin approval, ask your administrator or use the import from a personal account.

## Steps

1. Open **Settings** (gear icon in the sidebar).
2. Open the **Sync & Backup** tab and find the **Import/Export** section.
3. Click **Import from Microsoft To Do**.
4. Click **Sign in with Microsoft** and finish the sign-in in the browser window.
5. Review the preview: pick the lists to import. Lists whose name already exists as a project (for example from a previous run) and the **Flagged email** list are unchecked by default. Optionally tag important (starred) tasks with an `important` tag.
6. Click **Import**. The summary lists what was created and everything that could not be carried over.

## What is imported

- Lists, as projects (your default list becomes a project named like “Tasks (Microsoft To Do)”)
- Open tasks
- Steps, as sub-tasks (checked steps are imported as done)
- Task notes
- Categories, as tags (on tasks, not steps)
- Due dates
- Repeats that Super Productivity can express: every _n_ days, weeks, months or years, chosen weekdays, monthly on the due day, yearly on the due date, the first to fourth weekday of a month, and an end date. Other repeats keep their next due date, and the rule is added to the task notes (e.g. `Repeats: every month on the last friday`).

## What is not imported

- Completed tasks
- Reminders
- File attachments (the task is imported without the file)
- My Day, and links to emails or files
- Task order within a list

Unusually long list names, task titles, categories and notes are shortened to safe import limits. The preview reports how many selected values are affected.

If the import stops midway, delete the project named in the error because it may be incomplete. Then re-run the import and select that list and any remaining lists. To undo an import, delete the created projects.
