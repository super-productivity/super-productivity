# Board View

A **board**, shown as a **view** in the app, provides a visual, column-based way to organize tasks. Boards let you view and organize tasks from different perspectives using configurable columns (like Kanban or an Eisenhower Matrix) without changing the underlying task data. A board with one column works as a saved, rule-based task list.

## Where Boards Live

Every board is listed in the **Views** section of the sidebar, between the main pages and Projects, and opens on its own page (`#/boards/<id>`). The section is switched on and off with the **Views** switch under Settings → App Features (off on a new install).

- **+** next to **Views** creates a board. Saving opens it.
- **Save as view…** in a task list's sort/group/filter menu creates a one-column view with what that list shows: its project or tag (Today becomes "today or overdue"), its filter and its sort. Grouping isn't saved. Without a sort, the column starts in the list's order.
- On a view's page, the menu button in the title bar offers **Edit**, **Duplicate** and **Delete** (the same menu as the view in the side menu). A view with one column and one panel is shown at list width, as task rows like any task list: the same task actions and keyboard shortcuts, and completed tasks in a collapsible section. With **Manual** sort, rows are reordered by dragging or with the move up/down shortcuts; with any other sort the order follows it.
- Right-click a board (or long-press it, or use its menu button) to **Edit**, **Duplicate** or **Delete** it.
- Drag boards to reorder them.
- The **Views** start page and the phone bottom-navigation **Views** button open the board you opened last.

## What Problem Boards Solve

Boards solve the problem of **visual task organization**. They provide flexible, filterable columns that let you see tasks organized in different ways—by status, priority, urgency, or any other criteria you configure—while keeping the same underlying tasks.

For example, you might have a Kanban board with "To Do", "In Progress", and "Done" columns, or an Eisenhower Matrix with "Urgent & Important", "Not Urgent & Important", "Urgent & Not Important", and "Not Urgent & Not Important" quadrants.

## How Boards Work

Boards are made up of **panels** (columns). Each panel has:

- **Filters** that determine which tasks appear in that panel: tags (or only untagged tasks), completion status, scheduling, due date, deadline, time estimate, time spent, priority, one or multiple projects, backlog status, parent tasks only. They are the same rules as the task lists' filter menu.
- **Ordering** that you control by dragging and dropping tasks within the panel
- **Automatic updates** that modify task properties when you move tasks between panels

## Moving Tasks Between Columns

When you drag a task from one panel to another, the app automatically updates the task to match the target panel's configuration:

- **Tags** are added or removed based on the panel's tag filters
- **Completion status** is updated (marked done or undone) based on the panel's setting
- **Project assignment** is updated if the panel specifies a project
- **Scheduling** is updated (scheduled or unscheduled) based on the panel's setting
- **Due date** is set when the panel requires one: the task is planned for today, or for the first day of the range when today isn't in it (**Tomorrow**, **Next week**, **Next month**), keeping its time if it has one.
- **Deadline** is set to the **last** day of the panel's range ("due by"), or to today for **Today**. A deadline of today plans an unplanned or overdue task into Today, as everywhere in the app. **No deadline** removes it.
- **Priority** is set to the panel's priority.
- **Only untagged** removes all tags.

Some rules can't be met by changing a task: **Overdue** (planned date or deadline) and a minimum **time estimate** or **time spent**. Such a panel only accepts tasks that already match, shows a message when a move is refused, and has no add-task row. The same happens for rules that contradict each other.

This means moving a task to a "Done" panel marks it complete, and moving it to a panel that requires certain tags adds those tags to the task.

## Date Filters

A panel's **Due date** and **Deadline** filters are one of **Any** (default), **Overdue**, **Today or overdue**, **Today**, **Tomorrow**, **Next 7 days** (today and the six days after it), **This week**, **Next week**, **This month** or **Next month**; the deadline also has **No deadline**. Weeks start on the first day of the week from Settings. "Today" follows the **start of next day** setting, so a task due at 01:00 counts as due on the previous day when your day starts at 04:00. Overdue uses the same rule as the overdue tasks shown above Today. Tasks without a date never match a date filter, and setting a due date hides the panel's scheduled-state filter, because a due date implies "scheduled".

Panels can also sort by due date, deadline, creation date, title, time estimate, time spent, priority or tag (side-menu order), like the task lists' sort menu.

## Multiple Boards and Task Membership

Tasks can appear on **multiple boards simultaneously**. This works because:

- Each board panel independently filters tasks from active projects based on its criteria
- Tasks don't store which boards they belong to—membership is calculated dynamically
- Each panel maintains its own ordering, so a task can be in different positions on different boards

For example, a task might appear in the "Urgent" column of an Eisenhower Matrix board and also in the "In Progress" column of a Kanban board, with different positions in each.

Boards include tasks from projects that are hidden from the sidebar. Hidden projects are still active; only archived projects are removed from board task membership.

## Boards Vs Projects Vs Tags

| Feature               | Boards                             | Projects                          | Tags                                   |
| --------------------- | ---------------------------------- | --------------------------------- | -------------------------------------- |
| **Purpose**           | Visual organization with columns   | Task grouping and structure       | Cross-cutting categorization           |
| **Task Relationship** | Dynamic filtering-based membership | Direct assignment (required)      | Direct assignment (optional, multiple) |
| **Visual**            | Column-based layout                | Tree view in sidebar              | Badge display on tasks                 |
| **Persistence**       | Board configurations are saved     | Project data and task assignments | Tag data and task assignments          |

Boards provide a flexible visual layer on top of your existing task-project-tag structure. They let you create multiple simultaneous views of the same tasks without duplicating the underlying task data.

## Default Boards

The app includes two default boards:

- **Eisenhower Matrix** — Organizes tasks by urgency and importance (4 quadrants)
- **Kanban** — Organizes tasks by workflow stage (To Do, In Progress, Done)

You can create custom boards with your own panels and filters to match your workflow.
