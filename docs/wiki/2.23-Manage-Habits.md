# Manage Habits

Habits are for the recurring things you want to keep doing — water, a walk, reading, stretching — where a task you tick off once is the wrong tool. Each habit stores a single value per day, so instead of "done" you get a week grid you can look back on, plus an optional streak count.

## Open the Habits View

The **Habits** view is a top-level page next to Schedule and Boards. Click **Habits** in the side navigation. If you do not see it:

- Habits are disabled by default. To enable them, go to **Settings → App Features** and switch on **Habits** (see [[3.02-Settings-and-Preferences]]).
- There is no keyboard shortcut for the Habits view.

The page is a grid: one row per habit, one column per day for the last seven days. Above the grid are **Previous week**, the date range of the week you are looking at (e.g. `Oct 29 - Nov 4`), **Next week**, and a **Today** button to jump back. **Next week** is disabled when you are already looking at the current week — you cannot log future days.

## Add a Habit

1. Click **Add a new habit** at the bottom of the grid.
2. Fill in the settings dialog (titled `<your title> – Settings`).
3. Click **Save**. The new habit is enabled and appears in the grid immediately.

The **Save** button stays disabled until you change something.

| Field                                | What it does                                                                                                                                                                          |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Title**                            | The habit name. Shown in the grid, the top bar, and tooltips.                                                                                                                         |
| **Enabled**                          | If off, the habit leaves the grid and the top bar and moves to the **Disabled habits** section at the bottom of the page.                                                             |
| **Type**                             | **Stopwatch**, **Click counter**, or **Repeated countdown** — see below.                                                                                                              |
| **Icon**                             | A Material icon or any emoji. If you leave it empty, the first letter of the title is used instead.                                                                                   |
| **Countdown duration**               | Only shown for **Repeated countdown**. Defaults to 30 minutes.                                                                                                                        |
| **Track streaks**                    | Turns the counter into a habit tracker. When off, no streak is kept and the weekday settings below are cleared on save.                                                               |
| **Daily goal for successful streak** | The value that makes a day "successful". A plain number (minimum 1) for **Click counter** and **Repeated countdown**; a duration like `30m` (minimum 1 minute) for **Stopwatch**.     |
| **Streak tracking mode**             | **Specific weekdays** (default) or **Weekly frequency (e.g. 3 times per week)**.                                                                                                      |
| **Weekdays to check for streak**     | Only for **Specific weekdays**. Defaults to Monday–Friday. While **Track streaks** is on, these are the only weekdays that count towards the streak and the only ones you can log on. |
| **Completions per week**             | Only for **Weekly frequency**. A number between 1 and 7, defaulting to 3.                                                                                                             |
| **Hide toolbar button**              | Keeps the habit out of the top bar. See “Keep a Habit Out of the Top Bar” below.                                                                                                      |

### The three types

- **Click counter** — counts clicks. This is the type most habits want.
- **Stopwatch** — the habit measures elapsed time. Started and stopped from its top-bar button; the running value only accumulates while the app is open.
- **Repeated countdown** — counts down from **Countdown duration**, then shows a banner offering to count up and start the next session.

### Fill In a Day You Missed

Use **Previous week** to navigate back, then log the day there — the grid is not read-only. Up to seven days back at a time; you can keep going back as far as you like.

## Change a Habit's Settings

Click the habit's **name or icon** in the grid (or right-click it). The same `<title> – Settings` dialog opens, with a **Delete** button in its footer.

To set a specific value for a day, open the day dialog instead: **right-click** a grid cell, **long-press** it, or — for Stopwatch habits — simply **left-click** it. The dialog shows:

- **Current Streak** in days and your **Daily Goal** (only when **Track streaks** is on).
- A line chart of the last 28 days, with a dashed line marking the daily goal. Click a point in the chart to select that day.
- An **Edit for `<date>`** field to type the value directly — a number for click counters, a duration for stopwatches.
- A **Settings** button to jump straight to the habit's settings.

Click **Save** to apply.

## Reorder Habits

Drag a habit row up or down. The new order is saved and is the order used everywhere the habit appears.

## Disable, Re-enable, and Delete Habits

Clearing a habit's **Enabled** checkbox hides it from the grid and the top bar without losing its history. Disabled habits are collected at the bottom of the page under **Disabled habits (n)**. Expanding that section gives you three buttons per habit:

- the **eye** icon re-enables it,
- the **pencil** icon opens its settings,
- the **bin** icon deletes it.

Deleting asks you to confirm: _"Deleting a simple counter, will also delete all past data tracked on it. Are you sure you want to proceed?"_ There is no undo, so delete is the only destructive action here.

On a fresh install you start with three pre-made but **disabled** habits — **Standing Desk Timer** (stopwatch), **Coffee Counter** (click counter), and **Stretching Counter** (repeated countdown). Enable the ones you want from the **Disabled habits** section, or delete them.

## Where Habit Data Shows Up

- **Daily Summary** (reached via **Finish Day** in the task list): every enabled habit is listed with its value for that day, plus a 🔥 and the streak number when the streak is above zero. Clicking one opens the day dialog.
- **History**: expanding a day shows each enabled habit's value for it.
- **Metrics**: the **Simple Counters & Habit Tracking** section has **Click Counters over time** and **Stopwatch Counters over time** line charts.
- **Backups and sync**: habits are part of your app data, so they are included in full backups and exports — see [[3.06-User-Data]] and [[2.02-Restore-Data-From-Backup]].
- **Plugins**: the plugin API can read and write counter values — see [[3.01-API]].

## Things That May Surprise You

- The goal-reached toast and confetti fire from the stopwatch's running total, so you will see them for **Stopwatch** habits rather than for click counters.
- Turning **Track streaks** off discards your streak mode, weekdays, weekly frequency, and daily goal when you save.
- Changing a habit's type clears its countdown duration unless you picked **Repeated countdown**.
