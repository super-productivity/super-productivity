# Build Views with AI

Describe a view in plain words, like a kanban board, an Eisenhower matrix or a focus screen, and the built-in **AI View Builder** plugin has Claude write it. The view works with your real tasks inside Super Productivity, and you can keep refining it with follow-up requests. The plugin is off by default and optional.

## What you need

- An Anthropic API key from the [Claude Console](https://platform.claude.com/). Each generation is billed to that account.
- An internet connection while generating. Saved views keep working offline.

## Turn it on

1. Open **Settings** → **Plugins**.
2. Under **Other plugins**, enable **AI View Builder**.
3. Open **AI View Builder** from the main menu.
4. In **Settings**, paste your API key and click **Save key**. The key is stored on this device only; repeat this on each device where you want to generate views.
5. Optionally pick a model. **Claude Opus 5.5** gives the best results; **Sonnet** and **Haiku** are faster and cheaper.

## Build a view

1. Click **Create your first view** (later: **New view**).
2. Describe what you want, or start from one of the suggestions, and click **Generate**. Generating takes from several seconds to a few minutes; **Stop** cancels it.
3. To change the view, click **Edit with AI**, describe the change and click **Apply change**. **Undo last change** restores the previous version on this device.
4. Switch between views with the selector at the top. **Delete view** in the edit panel removes one.

If a view hits an error, a bar above it shows the message; **Ask AI to fix** pre-fills a fix request.

## What a view can do

A view can read your tasks, projects, tags, notes, repeat settings and simple counters, and it can add, edit, reorder and delete tasks, add and edit projects and tags, update counters, open a task's detail panel, and start or stop time tracking. Each view can also keep its own small settings, such as column definitions. Views and their settings sync with the rest of your data.

A view cannot delete projects, change app settings, read sync credentials, or reach the internet.

## Privacy

- Only your prompts and the source code of the view you are changing are sent to Anthropic. Your tasks, projects and notes are never sent: a view reads them on your device while it runs.
- Views run in a sandbox without network access, so a view cannot send your data anywhere, even if its code tried to.
- Your API key is stored like other plugin secrets: on this device only, never synced, exported or backed up.

## Limits

- The sandbox blocks browser storage, pop-ups, links to web pages and external images or fonts. Views use the app's own storage and theme instead.
- Very large views can be cut off; ask for a simpler version.
- A view built against today's API keeps working after app updates; views record the API version they were built for.
