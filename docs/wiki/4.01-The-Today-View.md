# The Today View

The Today View is the main place you work each day. It shows tasks whose due
day or due time falls within the app's **logical today**, so you can focus on
what matters right now.

## What It Shows

Tasks appear when their date-only due day is logical today or their specific due
time falls within logical today. The logical day starts at midnight by default.
You can move that boundary later under **Settings** → **Global Settings** →
**Misc Settings** → **Start time of next day**, which is useful if your working
day continues after midnight. The list updates when that configured boundary is
crossed. Tasks scheduled for later in the logical day may stay hidden until
their scheduled time.

The **order** of tasks in the Today View is the order you set. When you rearrange tasks there (for example by drag-and-drop or keyboard shortcuts), that order is saved and used whenever you open the Today view.

## How It Differs From Projects and Tags

The Today View is a **time-based** view. Other work views are **category-based**:

| Aspect                 | Today View                                                            | Projects and Tags                                  |
| ---------------------- | --------------------------------------------------------------------- | -------------------------------------------------- |
| **Which tasks appear** | Tasks due during logical today                                        | Tasks in that project or with that tag             |
| **Order**              | The order you set in the Today View                                   | The order you set in that project or tag           |
| **Updates**            | The list updates at the logical-day boundary or when due data changes | You add or remove tasks by changing project or tag |

You do not "add" or "remove" tasks from the Today View by tagging. Scheduling a
task for logical today puts it in the Today View; changing its due day or due
time to another logical day removes it.

## Planner and the Today View

When you move a task to today (for example via "Move to Today" or by setting its due date to today), it is removed from any planner day it was on. The Today View and the [[4.03-Planner-View]] both represent when work happens—today vs. future days—so a task is either on today's list or on a planner day, not both.
