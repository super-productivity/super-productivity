# Find Archived Tasks

When a task is archived it leaves your active task lists and there is no archive screen to browse. Two places bring archived tasks back: the **Search** page and the **History** view of the current project, tag, or Today. This how-to covers finding an archived task by search, reading one without leaving Search, and restoring one from History. For what the archive is and why it exists, see [[4.20-Task-Archiving]].

## Search for an Archived Task

1. Open Search — click **Search** (magnifying-glass icon) near the bottom of the sidebar, directly above **Upcoming**, or press `Shift`+`F`. The page header reads **Search**, the input is focused for you, and its placeholder is "Search for task or task notes". If Search is missing from the sidebar, switch it back on under **Settings → App Features → Search**.
2. Type part of the task **title** or part of its **notes**. Matching is case-insensitive and needs only a fragment, but you need at least one character.
3. Read the result list. Active tasks are listed first and archived tasks come after them, and the list stops after 50 results. An archived hit carries a small `archive` (archive box) icon beside the project or tag chip, and its title is struck through. A completed task that has not been archived yet is also struck through but has no archive icon — that is how you tell the two apart.
4. Click the result. For an archived task the app opens the **History** view of that task's own project (or its first tag), expands the day the task belongs to, and scrolls the task's row into view.

If nothing matches you get "No tasks found matching your search". Remember that Search covers **tasks only** — typing a project or tag name will not list projects or tags.

## Read an Archived Task Without Leaving Search

Every archived result has a small **info** (i) button next to the archive icon, with the tooltip "View task details". It opens a read-only dialog showing the task's subtasks, time spent against the estimate, notes, attachments, linked issue, repeat configuration, and the created and completed dates. There is no restore button in this dialog, and there is no restore action anywhere in Search.

## Restore an Archived Task

1. Open the **History** view of the work context the task belongs to: click the **⋮** button next to the context title in the header (its tooltip is "Project Menu") and choose **History**. The same menu is on the **⋮** button beside the project or tag in the sidebar, and on right-click there.
2. Expand the year, month, and day you are looking for (the current month is open already). History lists the context's archived tasks together with its active ones, filed under the day the time was logged; an archived task with no time tracked is filed under the day it was completed, or its creation date. Today's History is not filtered by project, so it shows archived tasks from all projects — use it if you do not remember which project a task was in.
3. Click the task's title to open the same read-only details dialog described above, or click the **restore** button at the right-hand end of the row (tooltip "Restore task from archive"). That button is only offered for top-level tasks that really are in the archive — subtasks come back with their parent.
4. Confirm with **Do it!**. The task and its subtasks are restored into its project's active task list and are no longer marked as done, and the app takes you back to the task list. (The confirmation dialog asks whether you want to move the task "into your Today task list"; that wording is misleading — the task lands back in its project, and the app returns you to the active task view.)

## Other Things Worth Knowing

- **The counters are hints, not links.** The **Working today:** figure in the header gains a "(+…)" amount when recently archived tasks in the current context have time logged today, and a task view with nothing left to show reads **All tasks completed** instead of **No tasks planned** when the only completed tasks left for today are already archived. Neither of these opens a list you can browse.
- **Archived projects are a different feature.** The "Show/hide projects" button in the **Projects** header lists **Archived projects (n)** when at least one project is archived; that page lists projects, not tasks, and it has its own "Search archived projects" box. See [[4.06-Project-View]].
- **Backlog is not the archive.** A project's backlog is a second, still-active task list, reached with the drag handle at the bottom edge of the project view. See [[4.20-Task-Archiving]].
