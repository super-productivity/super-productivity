# Import from TickTick

Bring your open TickTick tasks, sub-tasks, checklists, tags and due dates into Super Productivity in one pass. The import is **additive**: it only creates new projects, tags and tasks and never changes or removes existing Super Productivity data.

## What you need

- A **TickTick backup file**: in the TickTick web app, open **Settings → Backup** and click **Generate backup**. This downloads a `.csv` file. The file is read on your device only; nothing is uploaded.

## Steps

1. Open **Settings** (gear icon in the sidebar).
2. Open the **Sync & Backup** tab and find the **Import/Export** section.
3. Click **Import from TickTick**.
4. Choose the backup `.csv` file and click **Load preview**.
5. Review the preview: pick the lists to import (lists whose name already exists as a project — for example from a previous run — are flagged and unchecked by default) and optionally choose how to carry over TickTick priorities (see [Priorities](#priorities) below).
6. Click **Import**. The summary lists what was created and everything that could not be carried over.

## What is imported

- Lists, as projects (folders are flattened; lists with the same name in different folders become `Folder / List`; the TickTick Inbox becomes a project named “Inbox (TickTick)”)
- Open tasks and sub-tasks (Super Productivity nests two levels; deeper sub-tasks become direct sub-tasks of their top-level task)
- Checklist items, as sub-tasks of top-level tasks (checked items are imported as done). On sub-tasks the checklist is kept as a markdown checklist in the notes.
- Task content (into task notes)
- Tags (on top-level tasks)
- Due dates, including times
- Recurring tasks keep their next due date; the recurrence rule is added to the task notes (e.g. `Repeats: RRULE:FREQ=WEEKLY;INTERVAL=1`)

## Priorities

TickTick priorities are **off by default**. In the preview you can pick one of:

- **p1–p3 tags** — adds a `p1` (high), `p2` (medium) or `p3` (low) tag to each top-level task.
- **Eisenhower matrix** — reuses Super Productivity's built-in `urgent` / `important` tags: high → urgent + important, medium → important, low → urgent, none → neither.

Priority tags are only added to top-level tasks — sub-tasks in Super Productivity can't hold tags.

## What is not imported

- Completed, archived and won't-do tasks, and lists that contain only such tasks
- Folders and kanban columns (task order is preserved)
- Tags and mapped priorities on sub-tasks
- Reminders
- Recurrence rules as real repeating tasks — recreate important ones via [[2.06-Manage-Repeating-Tasks]]
- Attachments, comments, focus records and habits (they are not part of the TickTick backup)

Unusually long list names, task titles, tags and task notes are shortened to safe import limits. The preview reports how many selected values are affected.

The importer reads the column names of an English backup. If it reports that the file is not a TickTick backup and TickTick is set to another language, try switching TickTick to English and generating the backup again.

If the import stops midway, delete the project named in the error because it may be incomplete. Then re-run the import and select that list and any remaining lists. To undo an import, delete the created projects.
