# Week View

The **Week** view shows today and the next six logical days, stacked vertically.
It is a short, fixed window on the same days the [[4.03-Planner-View]] covers.

## What a Day Shows

Each day is the same day block the Planner renders, built from the same data,
so the two views never disagree about a day:

- **Planned tasks** — in the order you arranged them in the Planner
- **Timed tasks and calendar events** — in the day's scheduled section, with
  their start times
- **Recurring tasks** — as projections on the days they will occur, until a real
  instance exists for that day
- **Deadlines** — tasks whose deadline falls on that day

Days with nothing planned show the same empty state as in the Planner, and
completed tasks stay visible on their day rather than disappearing.

## Working in the Week View

Because the days are the Planner's own day blocks, they behave the same:

- Drag a task onto another day to move it
- Add a task inline to a specific day
- Reorder tasks within a day
- Use the same keyboard navigation and multi-select as the Planner

Any change made here shows in the Planner, and a change made in the Planner
shows here. Use the Planner when you need a longer planning horizon than a
week.
