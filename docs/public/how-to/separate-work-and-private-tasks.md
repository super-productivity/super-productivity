# Separate work and private tasks

> **How-to guide**: Shows how to keep work and private tasks apart in Super Productivity and still plan both in one Today.
> Use it when one list mixes your job with the rest of your life.

The app has no separate "area" above projects.
Project folders in the side menu take that role, and Today keeps showing the tasks of every project.

## Group your projects into folders

1. In the side menu, click **Create project folder** next to **Projects**, and name the folder `Work`.
2. Create a second folder `Private` the same way.
3. Click **Create project** next to **Projects** for each list that you need, such as `Acme` or `Household`.
4. Drag each project onto its folder in the side menu.
   To create a project directly inside a folder, open the folder's menu and choose **Add project**.

Folders can hold subfolders, so a folder `Work` can contain one folder per client.

## Add new tasks to the right project

A task added inside a project belongs to that project.
A task added from Today or another view goes to the default project, which is the Inbox.

- To send those tasks to a work project instead, open **Settings → Tasks** and pick it under
  **Default project to use for tasks if none is specified**.
- To pick the project while you type, add `+` and the project name to the title, such as `Send invoice +Acme`.

## Label tasks that cross projects

Use a tag for a context that both sides share, such as `phone` or `errand`.

1. Click **Create tag** next to **Tags** in the side menu.
2. Add the tag to a task with `#` in the title, such as `Call the dentist #phone`, or with **Tags** in the add-task bar.

The tag's view in the side menu lists its tasks from every project.

## See only one side in Today

1. Open **Today**.
2. Click **Open filter/group/sort menu** in the header, or press `C`.
3. Choose one of these:
   - **Group By → Project** shows work and private tasks under their project names.
   - **Filter By → Project**, then type part of a project name, shows only the projects whose name contains it.

The app keeps the choice for each view on this device.
Choose **Reset All** in the same menu to see every task again.

## Hide projects you do not use daily

1. Click **Show/hide in sidebar** next to **Projects**.
2. Click each project that you want to hide.

A hidden project leaves the side menu only.
Its tasks still appear in Today, and you can still move tasks into it or pick it with `+`.

## Check the result

The side menu shows the folders `Work` and `Private` with their projects.
Today lists the tasks of both, grouped or filtered the way you chose.
