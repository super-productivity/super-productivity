# Complete tasks from global search

1. Open global search with **Shift+F** and enter a term that matches your tasks.
2. Select the check mark beside the task you want to complete. The task disappears from the default results.
3. Select the check mark beside the next task. The search stays open and keeps your query.

To see the tasks you finished, select **Include completed and archived tasks**. Completed tasks appear with a line through their titles.
