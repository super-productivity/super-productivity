# Turn off features you do not need

> **How-to guide**: Shows how to switch off the parts of Super Productivity that you do not use.
> Use it when the side menu or the header shows features that get in your way.

Turning a feature off hides it and stops what it does.
Your tasks and the data of the feature stay, and switching the feature back on restores it.

## Turn off a feature from where you see it

1. Right-click the feature's entry in the side menu, such as **Planner**, **Schedule**, or **Habits**.
   On a touch screen, press and hold the entry.
2. Choose **Disable feature**.

The entry disappears, and a message offers **Open Settings** to switch it back on.

To turn off time tracking this way, right-click the play button in the header while there is a task to track, and choose **Disable feature**.

## Turn off any feature in the settings

1. Open **Settings → General**.
2. Under **App Features**, switch off each feature that you do not use.

| Switch        | What switching it off hides                                               |
| ------------- | ------------------------------------------------------------------------- |
| Planner       | The **Planner** view, where you drag tasks onto the coming days           |
| Schedule      | The **Schedule** view and the time grid next to your task list            |
| Views         | Saved views in the side menu, such as a board across projects             |
| Habits        | Habit tracking with daily check-ins                                       |
| Time tracking | The play buttons that start and stop a timer on a task                    |
| Focus mode    | The full-screen view that shows one task and a timer                      |
| Finish day    | The **Finish Day** button below today's tasks and its day summary         |
| Issues panel  | The side panel that imports issues from GitHub, Jira, GitLab, and others  |
| Project notes | The notes panel of a project or tag                                       |
| Sync button   | The sync button in the header; sync itself keeps running if you set it up |
| Search        | The search entry in the side menu                                         |
| Donate page   | The donate entry in the side menu                                         |

The **Time tracking** switch also sits at the top of **Settings → Time & Tracking**.

A new install starts with the Schedule, Views, Habits, Focus mode, Finish day, and the issues panel switched off.
An install that already holds data keeps the switches that you set.

## Check the result

The side menu lists only the features that are still on.
With **Time tracking** off, the play buttons are gone from the header and from the tasks.
