### Tasks and planning

- Restore an archived task from its details, with its edits intact.
- Search now tells you when only completed tasks match. In the schedule, you can open the full task list from the day panel.
- Future repeats keep moved subtasks and leave out removed ones. Reminders make clear which occurrence they apply to, and dismissing a reminder keeps your task draft.
- The add bar, calendar and time estimate dialog respect your custom day start. Editing a different day in the estimate dialog preserves time tracked while the dialog is open.

### Android widgets

- Choose a project for each widget. Tasks you add from a project widget go straight to that project. You can also show Inbox in a widget or use it as your start page.
- The Today widget opens Today and updates when the day changes. Widget checkboxes have larger touch targets and screen reader labels, and taps to complete tasks are more reliable.

### Import and help

- Start an import from the first onboarding tip, then open the imported project from the summary. Import and export settings are now grouped by purpose.
- Show or hide help text, follow links to the docs, or explore example setups in the new first-week guide.

### Sync, privacy and integrations

- When a task is marked done on one device and added to Today on another, sync keeps both changes.
- Anonymized exports mask GitHub and CalDAV server URLs. Exported logs redact home folder paths under `/var/home`.
- Azure DevOps issues now show acceptance criteria and system info. You can also add tags when creating tasks through MCP.
