# Production: edit

Edit handles a page that already has a home: an existing owner being updated, or a triaged target whose owner exists.
It answers *How should this page change?* and produces the edited page.

1. Open the owner's contract in [contracts.md](contracts.md).
2. Move the primed facts, links, and passages into their places; update the existing page instead of writing beside it.
3. Edit for content and structure only; voice and mechanics come later.
4. Cross-link with the Related block ([contracts.md](contracts.md)).

When the fact already has an owner, update that owner.
When the target is raw and unassessed, go back one step to [triage.md](../1-analysis/triage.md).
When no owner exists, use [create.md](create.md).
